# API reference (summary)

Full interactive docs are auto-generated by FastAPI at `/docs` (Swagger UI) and
`/redoc` when the server is running.

All endpoints except `/api/auth/login`, `/api/auth/refresh` and `/api/health` require
`Authorization: Bearer <access_token>`.

## Auth
| Method | Path | Notes |
|---|---|---|
| POST | `/api/auth/login` | `{username, password}` → access + refresh token |
| POST | `/api/auth/refresh` | `{refresh_token}` → new token pair |
| GET | `/api/auth/me` | current user |

## Dashboard / platform
| Method | Path |
|---|---|
| GET | `/api/dashboard` — KPIs, alerts, survival check, fuel, cold-chain summary, weather |
| GET | `/api/health` — no auth required, used for container health checks |

## Missions, assets, personnel, inventory (`routers/ops.py`)
| Method | Path |
|---|---|
| GET/POST | `/api/missions` |
| GET | `/api/missions/{id}` |
| PATCH | `/api/missions/{id}/status` |
| GET/POST | `/api/assets` |
| PATCH | `/api/assets/{id}` |
| GET | `/api/personnel`, `/api/teams` |
| POST | `/api/checkins` |
| GET | `/api/inventory` |
| POST | `/api/inventory/{id}/adjust`, `PATCH /api/inventory/{id}` |

## Cargo (`routers/cargo.py`)
| Method | Path |
|---|---|
| GET | `/api/cargo`, `/api/cargo/rules` |
| GET | `/api/cargo/consignments/{id}/check` — air-weight + hazard check |
| GET | `/api/cargo/{id}/history` |
| POST | `/api/cargo/{id}/handoff` |

## Safety (`routers/safety.py`)
| Method | Path |
|---|---|
| GET | `/api/risk/routes` |
| POST | `/api/risk/score` — what-if score from manual inputs |
| GET | `/api/coldchain`, `/api/coldchain/{id}` |
| POST | `/api/coldchain/{id}/readings` |
| POST | `/api/coldchain/{id}/simulate-delay`, `/reset-simulation` — demo only |
| GET | `/api/sar/status`, `/api/sar/incidents` |
| POST | `/api/sar/scenario` — demo helper: makes Team Bravo overdue and opens an incident |
| POST | `/api/sar/incidents`, `/api/sar/incidents/{id}/close`, `/api/sar/reset` |
| GET | `/api/env/weather` |

## Sync (`routers/misc.py`)
| Method | Path |
|---|---|
| POST | `/api/sync/push` — `{device_id, events:[...]}` |
| GET | `/api/sync/pull?since=<cursor>&device_id=<id>` |
| GET | `/api/sync/log`, `/api/sync/conflicts` |
| POST | `/api/sync/conflicts/{id}/resolve` — `{choice: "server"|"device"}` |

## Assistant / reports
| Method | Path |
|---|---|
| GET | `/api/assistant/suggestions` |
| POST | `/api/assistant/ask` — `{question}` |
| GET | `/api/reports/audit`, `/api/reports/*.csv` |

## GeoJSON layers
| Method | Path |
|---|---|
| GET | `/api/geo/coastline`, `/api/geo/iceshelves` — real Natural Earth data |
| GET | `/api/geo/seaice` — synthetic, `properties.synthetic: true` |
| GET | `/api/geo/features` — live points/lines (stations, teams, assets, routes, incident, SAR grid) |
